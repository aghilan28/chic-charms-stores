# Chic Charms Local Image Filename Map

All files below must be placed in:

`C:\Users\AKILA\Downloads\CHIC CHAMS\images`

Supported formats:

`.jpg`, `.jpeg`, `.png`, `.webp`

The filenames below use `.jpg` as the canonical mapped name from the original migration. The website now keeps that mapping intact but will automatically try the same basename with `.jpeg`, `.png`, and `.webp` if the canonical file is not present. Example: a slot mapped as `images/hero-quiet-luxury-main.jpg` will also load `images/hero-quiet-luxury-main.png`, `images/hero-quiet-luxury-main.jpeg`, or `images/hero-quiet-luxury-main.webp` without code changes.

## Dynamic Product Images

These product images were being loaded from Firestore as `product.image` / `p.image`. The site now maps the live product name to a local filename.

Exact code replacement in `index.html`:

Replace:
`src="${product.image}"`

WITH:
`src="${productLocalImage(product)}"`

Replace:
`src="${escapeStr(p.image || "")}"`

WITH:
`src="${escapeStr(productLocalImage(p))}"`

Exact code replacement in `product.html`:

Replace:
`src="${product.image}"`

WITH:
`src="${productLocalImage(product)}"`

Replace:
`src="${p.image || ''}"`

WITH:
`src="${productLocalImage(p)}"`
